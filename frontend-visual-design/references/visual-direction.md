# Visual direction and refinement

Use this reference for marketing, editorial, campaign, or an explicitly approved new visual direction. Do not apply it mechanically to internal tools, settings forms, accessibility fixes, or narrow changes that should preserve an established product system.

## Direction read

Commit to one short direction before implementation:

1. Audience and primary job
2. Promise, proof sequence, and primary action
3. One content-specific visual thesis
4. Typography, density, rhythm, and alignment
5. Meaningful interaction character

Ground every choice in product content, an approved reference, or an existing authority.

## Common ungrounded defaults

Review, rather than automatically ban, these patterns:

- purple-blue glow without brand evidence;
- reflexive Inter or Roboto replacement;
- centered dark-mesh hero with three equal cards;
- glass treatment across every surface;
- empty bento cells, decorative status dots, fake metrics, fake testimonials, placeholder brands, or div-based mock UI presented as a real capture;
- repeated alternating image/text sections with no information reason;
- motion used only as ornament.

Honest assets, real copy, legible hierarchy, supported behavior, accessible contrast, and one coherent system outrank novelty.

## One bounded refinement pass

After the real surface works, inspect hierarchy, spacing rhythm, typography roles, color emphasis, state feedback, generic-pattern residue, responsive composition, text scaling, localization, and reduced motion. Make only changes supported by the brief and rendered result, then rerun applicable checks. Do not turn polish into an open-ended perfection loop.
