# Visual reference discipline

Use this reference when a screenshot, mockup, generated concept, or authorized live capture materially influences implementation.

## Authority modes

- Current-surface delta: the implemented product and its design owner remain the target.
- Exploratory direction: the image may test hierarchy, density, or atmosphere but cannot direct production work until approved.
- Approved implementation reference: the reference is approved for a named target, state, content, and visual claim.

Before promotion, reconcile the user task, real content and states, semantic order, target platform, inputs, localization, accessibility, and current design authority. Generated text is never copy authority.

Record what to implement, what must adapt for real platform and content constraints, and what must be ignored because it is invented, unsupported, decorative, or outside scope.

Pixel comparison is meaningful only when the reference, target build, rendering environment, state, content, fonts, assets, and comparison method are controlled. It can locate drift but cannot decide behavior, accessibility, semantics, platform integration, or usability.
